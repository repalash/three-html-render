Privacy Policy

HTML-in-Canvas Polyfill browser extension

Last updated: 2026-04-12

Summary

This extension does not collect, store, transmit, or share any user data. It has no analytics, no telemetry, no remote servers, and no network requests.

What the extension does

The extension injects a client-side JavaScript polyfill into web pages to enable the HTML-in-Canvas web API. All processing happens locally in the browser tab. The extension:

  • Runs entirely on-device — no data leaves your browser
  • Does not read, collect, or transmit any personal information
  • Does not use cookies, local storage, or any persistence mechanism
  • Does not communicate with any external server or third-party service
  • Does not track browsing activity

Permissions

The extension requests access to all URLs (<all_urls>) solely to inject the polyfill script into web pages. This permission is required for the polyfill to function on any site the user visits. No data from these pages is collected or transmitted.

Data collection

None. Zero data is collected, stored, or transmitted. Since no data is collected, there is nothing to retain — no data retention period applies.

Data sharing and third-party disclosure

No user data is shared with or disclosed to any third party. The extension makes no network requests and uses no third-party services, libraries, or SDKs that collect data.

Uninstallation

The extension stores no data on your device. Uninstalling it removes it completely with nothing left behind.

Changes to this policy

If this policy changes, the updated version will be posted at this URL. The extension will never collect user data.
